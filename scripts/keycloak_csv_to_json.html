Keycloak CSV to JSON

Checks a user CSV and makes a file you can load into Keycloak. Everything happens in this browser tab. Nothing is uploaded or saved.

  1. Enter the Keycloak Client ID that holds the roles.
  2. Choose your CSV (or drop it below). Fix or remove any rejected rows.
  3. Download import.json.
  4. In the Keycloak admin console, realm opensrp: Realm settings, then Action, then Partial import. Choose the file, tick Users, set If a resource exists to Skip, then Import.
  5. Delete import.json afterwards.

Allowed roles: bkm-user (used when the role is empty) and bkm-supervisor. Any other role rejects that row.
