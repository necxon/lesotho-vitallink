Port map: what listens where, and who can reach it

Every TCP port the NEC stack binds, grouped by how far it is exposed. Only three ports are open to the public internet; everything else is reachable from the internal network, from the host loopback, or only from inside the Docker network. Each component system can also be pointed at a partner-hosted instance on another IP — those are outbound connections, listed at the end.

Data flow
  • Citizen or VHW reaches the gateway on 443; nginx forwards to the matching internal port.
  • App transactions land on OpenHIM 5001, which routes to the mediator on 3000.
  • The mediator fans out to OpenSRP, LMIS and DHIS2 and composes the response.
  • Only safe-to-show data returns; the public tier never touches raw records.
Deployment variants
  • Domain server: firewall allows 22, 80, 443 only; every service port stays on loopback.
  • IP-only bring-up with no domain: the service ports listed as internal are opened directly with ufw allow, and traffic is plain HTTP.
  • Sandbox / laptop: the same ports bind on localhost with no firewall in front.
  • Mixed hosting: point any component system at a partner instance on another IP; the in-stack container can then be dropped, freeing its host port.
